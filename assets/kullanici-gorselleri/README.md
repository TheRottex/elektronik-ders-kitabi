# Kullanıcı Görselleri

Bu klasör, daha sonra eklenecek devre fotoğrafları, breadboard görüntüleri veya öğrencinin kendi çizimleri içindir.

## Görsel ekleme

1. Görseli bu klasöre kopyala; dosya adını kısa ve anlaşılır tut (`seri-devre-kurulum.jpg` gibi).
2. Kaynağın/çekimin kime ait olduğunu ve izin durumunu not et.
3. İlgili ders Markdown dosyasında göreli bağlantı kullan:

   ```markdown
   ![Seri devre breadboard üzerinde](../../assets/kullanici-gorselleri/seri-devre-kurulum.jpg)
   ```

4. Görselin altında ne gösterdiğini ve devrenin hangi noktasının önemli olduğunu açıkla.
5. Kaynak ders kitabının tam sayfa görüntüsünü veya yetkisiz internet görselini yükleme. Önce kendi çekimini, kullanım izni olan görseli veya yeniden çizilmiş şemayı tercih et.
