# Sınava Odaklı Çalışma — 1. Senaryo (Elektronik Uygulamaları)

Ankara İli Bilişim Teknolojileri Alanı, 11-12. sınıf seçmeli Elektronik Uygulamaları konu soru dağılım tablosu — **1. Senaryo: 8 soru**.

| Öğrenme birimi | Kazanım | Soru | Çalışma |
|----------------|---------|:----:|---------|
| Analog devre elemanları | Devreye göre **direnç** seçimi | 1 | [§1](01-elektronik-sinav-calismasi.md) |
| | Devreye göre **kondansatör** seçimi | 1 | [§2](01-elektronik-sinav-calismasi.md) |
| | Devreye göre **bobin** seçimi | 1 | [§3](01-elektronik-sinav-calismasi.md) |
| | Devreye göre **diyot** seçimi | 1 | [§4](01-elektronik-sinav-calismasi.md) |
| | Devreye göre **transistör** seçimi | 1 | [§5](01-elektronik-sinav-calismasi.md) |
| | Devreye göre **transformatör** seçimi | 1 | [§6](01-elektronik-sinav-calismasi.md) |
| Temel devre uygulamaları | **Seri** devre kurma | 1 | [§7](01-elektronik-sinav-calismasi.md) |
| | **Paralel** devre kurma | 1 | [§8](01-elektronik-sinav-calismasi.md) |

1. Senaryoda **karışık devre sorusu yoktur**; ama paralel/seri bilgisi karışık devreler için de temeldir.

## 3 günlük plan

| Gün | Yap | Ölçüt |
|-----|-----|-------|
| 1 | §1 direnç + §2 kondansatör + §3 bobin | Renk kodu ve kondansatör kodu okuyorum |
| 2 | §4 diyot + §5 transistör + §6 trafo | Sembol, uç ve sağlamlık testini söyleyebiliyorum |
| 3 | §7–§8 + [deneme sınavı](02-deneme-sinavi-ve-cevaplar.md) | 8 sorudan en az 7 doğru |

## Mikrodenetleyici — 1. Senaryo

Mikrodenetleyici dersinin 1. Senaryo konu-soru tablosu henüz eklenmedi. Tabloyu paylaşınca bu bölüme ayrı çalışma dosyası eklenecek. O zamana kadar ortak kaynaklar: [sayı sistemleri](../senaryo-2/02-mikro-sayi-sistemleri-sinav.md) ve [lojik/entegre](../senaryo-2/03-mikro-lojik-entegre-sinav.md).
